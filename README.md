# Soundbook

Practise reading and handwriting English sounds with Hangul. The 46 cards cover individual symbols, syllables, words, and short phrases. The sound guide explains the notebook’s approximate spellings for English.

## Run it

Open `index.html` in a modern browser, or serve the repository directory using `python3 -m http.server`. The app is a single HTML file with embedded CSS and JavaScript.

## Practise

Choose a level and switch between Writing and Reading. In Writing, trace with a Pencil, finger, or mouse. Hide the guide to practise from memory and reveal it to compare. In Reading, select the English sound or phrase that matches the Hangul card.

Your browser stores the last card, level, and practice mode locally.
